#วิธีล้างข้อมูล Chrome บน Android ในกรณีที่ version แก้ไขไม่เปลี่ยน 

1.ตั้งค่า (Settings) → แอป (Apps) → Chrome → ที่เก็บข้อมูล (Storage)
2.กด ล้างแคช (Clear cache)
3.กด ล้างข้อมูลทั้งหมด (Clear all data / Manage space → Clear all data)
4.เปิด Chrome ใหม่ แล้วเปิดลิงก์ .../index.html ตามปกติ
5.เมื่อ Chrome ขอใช้กล้อง กด อนุญาต
